# FiTechHub

A read-only mother dashboard for Kronos VN v2, FiTechML, FiTechSNM, FiTechRNV3, Stock Monitor and LunaVN.

Public mode uses a selected metadata snapshot. It cannot read the Windows machine or run jobs. Six child dashboard read-only snapshots are bundled under dashboards/. Their filters, metadata and supported read views use frozen data. Live jobs, source-PC access, raw execution evidence and unsupported backend actions are unavailable. FiTechHub replaces the former FiTechRNV3 website at the same Pages address. This dashboard does not grant scientific acceptance or execution.
