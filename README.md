# FiTechHub

A read-only mother dashboard for seven modules: Kronos VN v2, FiTechML, FiTechSNM, FiTechRNV3, Stock Monitor, LunaVN and Fundamental Panel, with QRW as the shared data-governance foundation.

Public mode uses a selected metadata snapshot. It cannot read the Windows machine or run jobs. Eight child dashboard read-only snapshots are bundled under dashboards/. QRW is monitor observation only; it does not complete source task P10 or operational data cutover. Their filters, metadata and supported read views use frozen data. Live jobs, source-PC access, raw execution evidence and unsupported backend actions are unavailable. FiTechHub replaces the former FiTechRNV3 website at the same Pages address. This dashboard does not grant scientific acceptance or execution.
